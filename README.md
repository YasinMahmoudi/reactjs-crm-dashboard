##  🛠️ Installation 

Clone the project

```bash
 https://github.com/YasinMahmoudi/reactjs-crm-dashboard.git
```

Go to the project directory

```bash
  cd reactjs-crm-dashboard
```

Now you have 2 directories : client & server 
Install the project dependencies using pnpm for each part by navigating to each directory . 

```bash
  cd client 
  npm install

  &&

  cd server
  npm install
```

Set Up Environment Variables for your project based on ```.env.example```


Start the client : 

```bash
  npm run dev
```


Start the nodejs server : 

```bash
  npm start
```
